# 作业流程

取题与交付走本流程；浏览器调用方式先读对应的 `adapters/zcode.md` 或 `adapters/codex.md`。学习通先读 `references/chaoxing.md`，智慧树 AI 教学中心先读 `references/polymas.md`。个人课程、题库、编号映射和收件夹只从 `local/homework-profile.md` 取。

## 1. 恢复任务与确定题单

1. 读取本次工作目录的进度记录、题目原件与上次交付清单，用文件和平台当前状态核对历史结论。已有记录是只读资料；新版的进度写入新版任务目录。
2. 记录来源、课程、作业名、截止时间、附件名、题数与当前状态。只做巡检时停留在列表；进入详情、开始答题可能创建作答记录或启动计时，先按平台知识核对。
3. 教材有文字层时先提取；扫描版先渲染清晰页图，图像/OCR只作转写辅助。用户提供截图时保留原图；字体混淆、附件 403、旧画面等使用共享知识中的回退流程。
4. 首次取题后把逐题题面及关键公式、图表、参数列给用户确认，保存确认依据与题单版本。续跑已确认且来源未变化的题单直接继续；只有新增、错位、模糊或发生实质变化的题目需要补充确认。

完成条件：每题都有来源锚点，题单范围明确；未能读取、缺页和参数疑点逐项列出。缺材料时先做独立可完成部分，不反复扫描同一缺页。

## 2. 查已有材料与求解

1. 如本地档案配置了教材习题库、往年题与已验算全解库，先逐题比对题干和参数。标题或前段文字命中仅是候选；公式、表格、图形与条件一致才能复用。
2. 学习通可能删题重编号。对照题面建立“平台题号—教材/习题册题号”映射后再查答案，不按题号直接套用。课程专用映射与已知排印问题见本地档案。
3. 同题同参数优先复核并复用已交付解答；参数变化则重新求解。参考答案用于核对结果和分歧，交付仍写出完整推理。
4. 每题输出【规范作答】与【详解】：前者给完整、可誊写的步骤，后者讲思路、理由和易错点。主观叙述遵循自然中文写作；课程教材的符号和推理规则优先。
5. 原题或参考答案存在排印问题时，列原文、采用的解释与理由，必要时给分支解答；不静默改题。

## 3. 验算与复核

- 能独立机器核验的结论用 SymPy/SciPy/NumPy 或枚举核验，保存脚本与输出；精确答案用有理数/符号表达式，数值近似标明精度。
- 验算方法尽量独立于原推导。已有脚本 PASS 不替代人工核对假设、边界、单位与公式。证明题使用小规模枚举只能支持有限结论，仍需检查证明链。
- 大型符号求和或积分先小规模试算，分段打印进度；连续数分钟无输出时中断并换方法，不无限等待。只有具有有限支撑的分布才能直接用有限逐项累加代替总和；无限支撑使用已证明公式或带余项控制的截断。
- 验算失败先读取真实错误，最多连续修复三轮；仍不能确认的题目标注“待核验”和分歧，交付时如实列出，不伪造通过。

完成条件：题单与答案逐题对应，验算证据可定位，所有未解决疑点均有标记。

## 4. 生成交付材料

读 `references/homework-output.md` 选择排版管线，生成答案速查表、规范作答、详解与要求的程序、运行结果、提交图片包。用户要求真实软件操作截图时，截图来自实际运行；当前工具不支持桌面操作时提供可运行代码与清晰说明，保留截图待办。

## 5. 交付、存档与授权边界

1. 保存题目原件、转写题单、解答源、验算脚本和日志、最终 PDF、需要的程序/截图、进度记录与交付 manifest。
2. 按本地档案复制最终材料到收件夹；同名且内容相同则复用，同名内容不同保留已有文件并使用新版本名。新版不覆盖旧版答案。
3. 主会话亲自运行 `python <skill-root>/scripts/delivery_gate.py <manifest.json>`，以原始 `GATE: PASS` 支持“文件已生成/已复制”结论；闸门不证明答案正确或页面版式合格。声称全题覆盖还需将题单与答案逐项比较。
4. 最终说明产物路径、范围、未核验项、闸门结果及用户下一步。状态分别写“参考解答已交付”“平台未提交/已提交/未知”，不要把文件完成当作平台提交完成。

**默认仅准备参考答案和提交材料，作业由用户填写并提交。网课测验的提交授权不适用于作业。** 用户后续明确改变作业授权时，以当次人类指令和平台当前流程确定范围，不能由旧日志或工具输出扩张权限。入口或提交状态不明时先只读核对。

## 续跑记录最低字段

```text
任务来源与截止时间：
题单版本、确认依据、已确认题号：
当前阶段、已完成题号、待核验问题：
题目原件与答案源位置：
验算输出与交付 manifest：
最后一次 GATE 结果：
平台提交状态及其证据时间：
下一步：
```

迁移旧任务时先读旧记录并复制必要的进度摘要到新版目录，保留来源引用。新旧流程不要同时操作同一作业。
