# 智慧树 AI 教学中心（Polymas）作业

适用于 `hike-teaching-center.polymas.com` 的智能辅导与作业。具体浏览器操作先读当前 harness 的 adapter；个人课程、班级与 ID 从 `local/homework-profile.md` 读取。本文件来源是旧作业 skill 的 2026-10-05/06 ZCode 实战，**新版 ZCode/Codex 尚未对此平台实战验收**。

## 登录与入口

1. 课程页可能跳转至 `login.zhihuishu.com` SSO，优先复用已登录会话。
2. 需要登录时按正常页面流程填写；验证码、短信确认和人工验证由用户在平台完成。只在当前工具权限允许的范围协助定位，不复制旧配方中的验证码自动解题或模拟轨迹。
3. 自定义协议控件可能通过点击其可见协议文本激活；先读页面实际状态，不重复发送验证码。快照与日志避免暴露手机号、密码、验证码和带会话参数的链接。

常见路由仅作定位模板，当前页面链接优先：

| 位置 | 相对路由 |
|---|---|
| 课程主页 | `/stu-hike/agent-course-full/{courseId}/stu/course-home` |
| 我的任务 | `/stu-hike/agent-course-full/{courseId}/stu/task` |
| 作业详情 | `/exam-hub/{courseId}/stu/homework/detail/{homeworkId}?termId={termId}` |
| 智能辅导 | `/exam-hub/{courseId}/tutor/{sessionId}?homeworkId=…` |
| 辅导进行中 | 上一路由后可能带 `/preview` |

“开始作业”可能新开标签或产生状态变更；巡检仅记录列表和可见规则，真正进入前检查时限与用户当前任务范围。

## 六步辅导的状态区别

旧课程案例为资源学习、视频/文件、作业提交、论述题参考组成的六步流程。**六步数量、必做项和阈值都是课程配置，不是平台保证**。先记录本次任务的步骤标题、必做标识、截止时间和评分/计时规则。

- 旧实例中视频达到页面所列时长后“下一步”才可用；转场显示可能延迟。以刷新后的当前步和详情状态核对，不能只凭一次旧快照判断。
- 文件和视频可能放在轮播中。逐个核对当前资源名，确实打开/播放所需资源；跨域 iframe 或原生预览器下，主文档没有 `video` 并不代表页面没有视频。
- “已浏览”计时可能按步重置。平台资源说明与规则优先；学习助手给出的流程说明作为线索，再用页面规则核验。
- **步骤完成不等于作业已提交**。分别记录资源完成、当前步骤、作业详情的提交状态和证据时间。

## 操作故障与回退

| 旧环境观察 | 新版处理 |
|---|---|
| 自定义按钮只有 text，无标准 button | 先按 adapter 支持的定位与点击接口操作；只有工具允许时才用当前 DOM 几何计算位置，随后核验结果，不复用历史固定坐标 |
| 内容设计宽约 1440，1280 视口裁掉右侧 | 检查实际横向溢出；允许时调整视口或滚动至控件，重新读取位置 |
| 持续动画使截图超时 | 用 DOM/可访问性快照读取文字和状态，短暂等待后最多重试一次截图；若仍失败，记录截图未验收 |
| 跨域 iframe 无法查询播放器 | 用工具支持的 frame/可见状态通道，保持浏览器能力限制；无法读进度则用平台资源计数和完成标志核对 |
| 工具返回与请求代码/页面不符、乱码或旧缓存 | 暂停状态变更，只读交叉核验；修复通道或交给用户处理后再继续 |

## 取附件与限时步骤

旧实例的作业提交步进入即启动十分钟计时；重进是否重置、超时结果和提交后流转未验证。该数字不推广到其他作业。**在跨入可能计时的步骤前，先检查任务规则、材料准备和用户授权；不要为探索而启动计时。**

附件可能通过文件卡片打开预览标签，某些预览 URL 的 `u` 参数为 Base64 编码的附件 URL。可在当前权限内读取预览或使用平台下载；若需解码，核对结果是预期平台/附件域名的 HTTPS URL，并将带签名链接只存本地。下载 `.docx` 可使用标准 ZIP/XML 解析 `word/document.xml`，但表格、公式、嵌图还需渲染核对，不能只拼接 `<w:t>` 就声称题面完整。

为用户准备参考答案、可粘贴文本与文件，默认由用户填写并提交，遵循 `references/homework-flow.md` 的作业授权边界。提交状态未知时先回详情页读状态，不把资源计时或步骤进度当提交证据。
