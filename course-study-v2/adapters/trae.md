# Trae 适配

明确选择 `course-study-v2` 后使用。Trae 中文版全局技能根为 `%USERPROFILE%/.trae-cn/skills`，
项目技能根为项目内 `.trae/skills`；以当前会话实际加载目录与工具文档为准。
官方说明：[技能](https://docs.trae.cn/ide_skills)、[浏览器控制](https://docs.trae.cn/ide_browser-use)。

先检查当前会话的文件、命令与受支持浏览器工具；内置浏览器与通过扩展连接的外部浏览器
是不同通道，不能套用其他宿主的工具名或假定共享登录态。缺少通道时记录缺口，不寻找隐藏调试接口。
新账号使用独立登录会话与任务目录；先核对账号、课程、已有授权及同账号其他执行器。

## 题面与工具

- Trae 安装副本记录的浏览器工具包括 `browser_navigate`、`browser_evaluate`、`browser_snapshot`、
  `browser_click`、`browser_fill`、`browser_wait_for`、`browser_take_screenshot` 与 `browser_tabs`；
  部分工具可由 Exec 中的 `tools.browser_*` 编排。名称、参数和单次调用时限以当前会话实测为准。
- 在允许页面脚本时，用 `scripts/browser_payload.py` 生成题面或列表采集函数并传入实际选项；
  题面回显被截断时，使用当前工具支持的分片或完整回执，核对题量和选项数，不解析截断 JSON。
  采集和离线处理的输入输出遵循 [工具数据格式](../references/tool-data.md)。
- 学习通混淆字体可用 `question_reader.py ocr --fallback-missing-glyphs` 辅助读取；
  回读结果、否定词、图片和选项标签仍需人工或视觉复核。跨帧或字体材料不可用时按
  [证据与效率](../references/evidence-efficiency.md) 的截图、OCR回退处理，不猜测未读内容。
- Trae 独立安装副本还记载过单节点批量取题、字体回退及测验首答100分；该记录保留为宿主自报，
  当前私有节点台账未包含对应结果，不把它当成已独立核验的新增完成数。

用户要求不占用前台时，先在已授权的单个未完成视频上验证：以真实播放器读回两次时间推进，
切换到其他应用或标签后再次回读，并在目录刷新后核验平台保存的完成标记。分别记录窗口被遮挡、
浏览器标签切换、最小化等实际条件；任一条件成功不能外推其他条件。若平台或通道要求持续占用
前台，保存断点并报告，不通过伪造心跳、修改进度接口或绕过平台限制来达到后台运行。

## 2026-11-07 学习通实测

- Trae CN 会话已加载本技能，并通过 Exec 中的 `tools.browser_*` 操作内置浏览器；实际接口仍以当前会话文档为准。
  课程目录、真实视频、章节测验提交与平台结果已有该宿主的运行记录。按账号单执行器、单标签顺序处理。
- 同一视频的单次样本中，切换标签约137秒和最小化窗口约135秒期间，播放器时间分别持续增长；
  播完后重新读取目录，平台任务点增加。记录也有自动暂停后恢复的情形，短时成功不证明长期稳定或锁屏有效。
- 后续出现“账号在多个谷歌内核浏览器登录”提示及页面跳回个人空间、播放中断。现有记录不足以证明
  多标签或后台播放就是触发原因；保留单账号单执行器与状态回读，遇到提示或跳转先停止并检查现场。
- 章节测验曾回读到80分，不能把流程成功当成答案必然正确；题面、选项、保存和平台结果应逐项核对。
- 课程状态和节点文件的内嵌时间戳与磁盘修改时间存在不一致；续跑须重新读取平台状态，不以旧时间或
  本地计数代替完成标记。会话与课程数据保留在私有运行目录，不进入技能公开内容。
- 其他课程、锁屏、进程退出和长时间无人干预条件未形成完整验收；已有豆包、WorkBuddy、Codex 或 ZCode
  结果不计为 Trae 证据。详细匿名能力边界见 [验证说明](../references/validation.md)。
