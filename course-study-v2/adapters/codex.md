# Codex 适配

资源根是本轮实际读取的 `course-study-v2/SKILL.md` 所在目录；运行记录写入独立目录。
先核对本轮授权、账号与执行归属，再按当前公开工具文档操作。DeepSeek 的独立安装和浏览器不参与此路径。

## 初始化与路由

1. 核对当前工具面。存在 `mcp__cua_repl` 时，首次调用只用工具文档规定的一个入口；读取返回文档，再复用浏览器和实际标签。恢复时先列标签，缺失才从正常课程入口恢复。
2. 普通页面用 DOM 快照与 locator；只回传当前任务所需片段，完整材料留本地。AX、DOM、CDP 的延迟会随页面变化，实测后选择。
3. 当前 `playwright.evaluate` 是只读；静音、DOM 点击与有界监听走本标签公开 `cdp` capability，先读其 `documentation()`。不连接隐藏端口或其他 harness 的 client。
4. 读取 [运行说明](../references/codex-runtime.md)，用带身份闸门的事务起播、观察和处理已解答弹题。没有 CDP 时使用普通控件和截图；无法可靠静音就保留暂停。
5. 视频结束后读取平台完成标记；章节测验分别核验保存、单次提交与结果，最后刷新目录。

## 按故障取资料

- 跨帧误跳、窄侧栏遮挡、静音、旧页面和字体采集调用：读 [对应故障说明](../references/codex-troubleshooting.md)。超时后先核对实际页面，不把超时当作未执行。
- 混淆字体或截图失败：仅采集当前题页字体，按 [数据格式](../references/tool-data.md) 使用离线 reader；复核题量、选项和否定词。没有可靠材料时保留未知。
- 作业交付：读作业流程及当前文档/PDF技能，保留用户自行提交边界。

原生控制是否可用以当前工具为准。DOM visibility 与浏览器面板可见性都不能证明操作系统窗口最小化。
缺少受支持浏览器通道时可做离线整理，但实时播放、作答和保存仍记未验证。
