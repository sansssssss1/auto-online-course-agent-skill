# DeepSeek Harness 适配

本页适用于明确选择 `course-study-v2` 后在 DSH 中工作。资源根是本轮实际加载的 v2 目录；
`course-study-dsh` 是独立维护的另一份技能。本版不读取、覆盖或同步它的安装、`local/`、账号配置和运行记录。
以下经验归纳自独立版近期改进；当前可用性仍以 DSH 本轮工具文档和现场核验为准。

## 浏览器与安装

DSH 通过已配置的 Playwright MCP 控制本机外部 Chrome，不使用 Codex/ZCode 的内置浏览器。
从当前工具清单选该账号对应的一条 `mcp__browser*__browser_*` 通道；一个账号、一个隔离 profile、一个受控标签、一个执行器。
工具名相似只说明有候选，不能证明跨帧读写、截图、下载或登录态可用。新增/重载 MCP 可能重启浏览器并丢失登录态，留给用户在节点边界配置。
不借用独立技能的活动浏览器，不查调试端口，不在 shell 另建 Playwright/CDP/Selenium 会话。缺少受支持通道时保留离线工作。

安装副本不随源码自动更新。用本版探针检查 `course-study-v2` 的发现顺序和整包清单：

```text
python scripts/dsh_probe.py --source <V2_SOURCE> --tools <CURRENT_TOOLS_JSON> --require-discovered --require-winner <V2_INSTALL> --require-clean --out <NEW_RUN_DIR>/probe.json
```

退出码 5 表示未发现，6 表示加载位置不符，7 表示清单或安装漂移；候选浏览器仍需现场验证。
不传 `--tools` 只检查文件发现，浏览器状态为 unknown。文件系统 winner 不能取代 harness 实际返回的 base directory。

## 授权与模式

沿用 [状态格式](../references/state.md) 的本次授权。没有章节测验作答/提交授权时保留只读，
不点选项、不提交、不重开。打开答题页也可能留下“已查看”记录或启动计时；只巡检时停在目录。
明确授权已存在时直接执行对应范围，模式文件不额外制造重复确认。

独立版新增了 `mode/submit/redo_once` 和 ASR 开关、题库/知识总结流程；这些属于它自己的配置契约，
不自动迁入本版，不把开启某个配置视为当前任务授权。付费/外发媒体的 ASR 需要另行明确选择；本版没有新增 ASR 调用。

## 单节点执行

1. 先读目录的服务器标记，分清只做视频、只做测验或二者都做。视频已由平台确认完成时直接进入已授权的测验流程，记录“既有完成”，不声称本轮播到了 ended。
2. 从正常目录导航，等题目或媒体实际渲染。对章节、附件、完整媒体路径逐个核验；一节可能包含多个视频，不能 `.find()` 后把首个视频当整节。
3. 在工具明确允许的同一次页面操作中组合导航后的读取、静音、正常起播与字幕地址发现。每个动作有真实回读，遇身份变化、弹题或未知结果立即返回。
4. 稳定播放用有界、只读的事件等待，只在结束、弹题、异常暂停、错误或预算到期时回短状态。脚本文件直载仅用于当前工具文档明确提供的 `filename` 能力。
5. 弹题题面、显示选项和真实选中态一起核对；章节测验按授权读取/保存/单次提交。结果未知先查平台记录，重做是新的明确事务。
6. 完成后刷新/重新读取目录并保存本次节点证据；侧栏旧角标可能是页面加载时的快照。视频 ended、弹题消失和点击提交分别不能替代服务器完成或答对证据。

旧播放器可能要求点真实 radio；新版测验可能使用 `li[qid]`。先探当前骨架，不复制上一页的输入 token。
日上限浮层可能位于 studentstudy 帧内；结合几何尺寸与实际可见性判断，触发即停当日视频任务。
使用当前平台公开控件允许的速率，记录实际读回和来源；锁速接受 1x，不照搬独立版的属性写速兜底。

## 等待与材料

DSH 独立版的 175 秒窗口以其通道 300 秒上限为前提，是历史经验，不是本版统一默认值。
先核对当前工具/服务端超时和传输预留；预算到期可继续只读观察，传输超时则先回查现场，不自动重放写操作。
`browser_evaluate` 是否传参数以当前实现为准；只接函数体的版本应将常量放进函数内。原生 Playwright 的 page 句柄只在其公开 run-code 工具中使用。

字幕先落盘，再用 `subtitle_evidence.py find/gate --brief` 和 `slice` 读取所需引文；正文不反复塞进上下文。
取不到字幕时先记录本媒体“无轨/未知”的证据，再按授权选择讲义、转写或人工补证，不反复抓同一空列表。
截图读取实际返回路径，复制到本次私有目录；OCR 缺题先用 [补读守卫](../scripts/ocr_guard.py) 一次裁剪重识别。
语义和选项证据流程见 [证据与效率](../references/evidence-efficiency.md)。

## 窗口与验收

外部 Chrome 导航可能抢前台；独立版有按专用 profile 筛选的最小化工具，但本版不导入它的 Win32 控制和常驻 watcher。
窗口操作只在当前宿主明确提供原生能力且任务允许时做。旧播放器可能失焦暂停；DOM visible、截图成功都不证明操作系统最小化或后台闭环。
独立版自己的成功记录不算 v2 已复测。分别报告平台结果、离线校验与未验证条件。
